POWER 1 V2 — PRUEBA RÁPIDA

ROCK inicia en BASE.
S,S rápido abre el mini selector.
S,S,W = CUT / CONCRETE.
S,S,S = BASE / BUSTER.
(FIRE y LEAF/SNAKE quedan reservados.)

CUT / CONCRETE:
J = Concrete largo/móvil.
S + J = Concrete cercano/fijo.
M = Rolling Cutter corto tipo boomerang.
I = Beat.
K = Rush Jet; S+K = Rush Coil.

Límites Concrete:
- 2 cercanos.
- 1 largo.
- largo: cooldown aprox. 2.8 s después de romperse.
- plataforma desde frame 7.
- Rock puede montar el largo.

Pruebas importantes:
1) Bass: una ráfaga completa debe romper un Concrete apenas.
2) X Buster máximo: debe romper Concrete de una.
3) Rush debe seguir por el suelo si Rock monta Concrete.
4) La estela es sólo visual y debe quedar detrás.
5) Cutter debe regresar a la posición actual de Rock.
