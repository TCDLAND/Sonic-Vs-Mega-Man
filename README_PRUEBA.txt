MEGA MAN VS SONIC - PROTOTIPO

IMPORTANTE:
- Abre ESTA carpeta (la que contiene index.html) en VS Code.
- Si usas la extensión Live Server: clic derecho sobre index.html > Open with Live Server.
- Si no aparece esa opción, revisa que la extensión "Live Server" de VS Code esté instalada y habilitada.

SELECCION:
P1: A / D, confirmar J
P2: flechas izquierda / derecha, confirmar coma (,)

SPIN DASH (Sonic, Shadow, Espio, Silver, Knuckles):
P1: mantener S + pulsar ESPACIO hasta 3 cargas; soltar S para salir.
P2: mantener flecha abajo + pulsar ENTER hasta 3 cargas; soltar flecha abajo.

Cada carga válida reinicia el mismo audio; no se superpone.
Tres cargas/sonidos = Nv.3.
Los tiempos entre cargas dependen del personaje.

Los nuevos personajes son CAJAS DE PROTOTIPO a propósito. X, Zero, Rock, Proto Man,
Eggman, Wily, Emerl y Mega Man Zero están creados/seleccionables, pero sus ataques
propios todavía no se inventaron ni implementaron donde no los habíamos definido.
